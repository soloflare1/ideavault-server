##  Core Functionalities

* **JWT Authentication** **
* **Database Management**
* **RESTful API Endpoints**

##  Tech Stack

* **Runtime & Framework:** Node.js, Express.js
* **Database:** MongoDB Native Driver
* **Security & Tokens:** JSON Web Tokens (`jsonwebtoken`), Cookie Parser (`cookie-parser`), CORS
* **Deployment:** Render
